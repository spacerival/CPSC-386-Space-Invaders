Class + Section: CPSC 386 Section 1
Assignment: Space Invaders
Description:
  A recreation of the classic arcade game "Space Invaders", coded with Python and the library "Pygame". This recreation features original music created via FamiStudio, animations, and a high score system.

What is required to run?:
  1. Python Installed
  2. Pygame Library Installed
  3. All files pulled from this repo

How to Run:
  Navigate to the "alien_invasion.py" file and run.

Controls:
  Movement with WASD
  Move Ship Up - W
  Move Ship Down - S
  Move Ship Left - A
  Move Ship Right - D
  Fire Lasers - Spacebar
  Click Play and High Score Button with Left-Click of mouse
